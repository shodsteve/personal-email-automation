# Personal Email Automation System

📧 **AI-powered email classification, smart labeling, and draft reply generation**

## Overview

A sophisticated email automation workflow that intelligently triages incoming emails, classifies them, applies appropriate labels, generates contextual reply drafts, and optionally creates calendar events—all while maintaining a **draft-only mode** to ensure human review before any action.

## Features

✅ **Gmail Integration**
- Webhook trigger on new emails
- Automatic label application
- Header analysis for reply detection

✅ **AI-Powered Classification**
- OpenAI GPT-4/3.5-turbo email analysis
- Multiple classification types: reply_needed, archive, action_required, follow_up, informational, spam, urgent
- Smart routing based on classification

✅ **Draft Generation**
- Contextual reply drafts generated by AI (OpenAI or Claude)
- Considers email tone, sender style, and user preferences
- Never auto-sends—always requires manual review

✅ **Calendar Integration**
- Automatic calendar event creation from emails
- Smart date/time parsing from email content
- Optional Google Calendar API integration

✅ **Smart Labeling**
- Automatic Gmail label application
- Project, client, and priority detection
- Customizable label mapping

✅ **Error Handling**
- Comprehensive error logging
- Graceful failure recovery
- Rate limiting protection

## Architecture

### Workflow Stages

1. **Receive** → Gmail webhook triggers on new email
2. **Clean** → Extract and normalize email content
3. **Classify** → OpenAI analyzes email intent
4. **Label** → Map classification to Gmail labels
5. **Check Headers** → Detect if reply is needed
6. **Split** → Route to reply or archive track
7. **Draft** → AI generates contextual reply
8. **Calendar** → Create event if needed
9. **Review** → Store draft for manual review
10. **Error Handling** → Log and alert on failures

### Key Components

- **18 Nodes** across the workflow
- **Multi-stage pipeline** with branching logic
- **Modular design** for easy extension
- **Draft-only mode** for safety and control

## Configuration

### Prerequisites

- n8n instance (self-hosted or cloud)
- Gmail account with API access
- OpenAI API key
- (Optional) Google Calendar API credentials
- (Optional) Claude API key for draft generation

### Setup Instructions

1. **Create Gmail Labels**
   - Go to Gmail Settings → Labels → Create new label
   - Create these labels:
     - `[Gmail]/Reply Needed`
     - `[Gmail]/Action Required`
     - `[Gmail]/Follow-up`
     - `[Gmail]/Archive`
     - `[Gmail]/Urgent`
     - `[Gmail]/Informational`
     - `[Gmail]/Spam`

2. **Add Credentials to n8n**
   - Gmail OAuth2 token
   - OpenAI API key
   - Google Calendar API key (optional)
   - Claude API key (optional)

3. **Configure Preferences**
   - Email signature
   - Reply tone (formal, casual, friendly)
   - Default calendar
   - Custom label mappings

4. **Test & Deploy**
   - Test with sample email
   - Enable Gmail webhook trigger
   - Monitor for errors

## Safety Features

🔒 **Draft-Only Mode** - Never auto-sends emails automatically

🔒 **Manual Review** - Every draft requires human approval

🔒 **Error Logging** - All failures are logged for debugging

🔒 **Rate Limiting** - Prevents API abuse

🔒 **Header Analysis** - Prevents accidental reply-all mistakes

## Classification Types

| Classification | Action | Gmail Label |
|---|---|---|
| `reply_needed` | Generate draft for review | [Gmail]/Reply Needed |
| `action_required` | Flag for action | [Gmail]/Action Required |
| `follow_up` | Track for follow-up | [Gmail]/Follow-up |
| `archive` | Auto-archive | [Gmail]/Archive |
| `urgent` | Highlight urgently | [Gmail]/Urgent |
| `informational` | FYI only | [Gmail]/Informational |
| `spam` | Remove/report | [Gmail]/Spam |

## Error Handling

| Error | Action |
|-------|--------|
| Email parsing failed | Log error, skip draft, send alert |
| API rate limit | Retry with exponential backoff |
| Calendar creation failed | Log error, continue classification |
| Authentication error | Pause workflow, require manual re-auth |

## Usage Workflow

1. Email arrives → Workflow automatically triggers
2. Email is classified and labeled in Gmail
3. If reply needed, AI draft is generated
4. Draft is stored in Notion/database for review
5. You review, edit if needed
6. You send manually from Gmail
